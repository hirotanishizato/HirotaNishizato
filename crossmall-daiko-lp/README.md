# CROSS NAVI — クロスモール 設定・運用 まるごと代行 LP

複数モール一元管理ツール「クロスモール（CROSS MALL）」の **導入・初期設定・在庫連携・受注運用** を代行する
サービス（運営：FANCAS合同会社）向けのランディングページ一式です。スマートフォン対応のレスポンシブ構成。

## 構成

```
crossmall-daiko-lp/
├── index.html      … メインLP（Hero／お悩み／できること／選ばれる理由／料金プラン／FAQ 他）
├── contact.html    … お問い合わせ・無料相談（デモフォーム付き）
├── company.html    … 会社概要
├── css/style.css   … スタイル（デザイントークン／レスポンシブ）
├── js/main.js      … モバイルメニュー／FAQ／スクロール出現／フォーム制御
└── assets/         … 画像等の追加素材を置く場所（現状は未使用）
```

## プレビュー方法

ビルド不要の静的サイトです。ローカルで簡易サーバーを立てて確認できます。

```bash
cd crossmall-daiko-lp
python3 -m http.server 8080
# → ブラウザで http://localhost:8080 を開く
```

`index.html` をブラウザで直接開いても表示できます（フォントはGoogle Fonts、その他はローカル）。

## このLPの設計意図（戦略メモ）

クロスモールが **メリット** として打ち出す価値は、裏返すと導入検討者の **お困りごと** そのもの、という調査結果を軸に構成しています。

| クロスモールの訴求（メリット） | 裏返した顧客の悩み（LPで刺す） |
| --- | --- |
| 在庫連携で売り越し・欠品防止 | 手作業の在庫更新で売り越し・欠品が止まらない |
| 受注一元管理で作業時間削減 | 受注処理に追われ、販促に手が回らない |
| 商品一括登録 | 各モールへの登録が二重三重で大変 |
| 多店舗運営の効率化 | 複数店舗運営で疲弊している |

さらに、導入でつまずく主因（**フルスペックゆえ難易度が高い／マニュアルがPDF中心で探しにくい／
商品マスタ・CSV・API連携など専門知識が前提／自社業務フローへの設計が必須**）を
「自力導入が難しい3つの理由」として明示し、**代行の必然性** に接続しています。

### 想定クライアント像（ペルソナ）
- 楽天・Amazon・Yahoo! 等で複数店舗運営する中小EC事業者・メーカー
- 売上は伸びてきたが、在庫・受注が手作業で限界。専任のEC担当がいない（社長／少人数兼任）
- クロスモールを「契約したが使いこなせていない」or「導入前で不安」
- CSV・マスタ設計・API連携などの専門知識がない
